模块端点 / 来源说明
报价 & 日线 Yahoo Finance v8 Chart API
query1.finance.yahoo.com/v8/finance/chart/{ticker}		 实时股价、历史OHLCV、前收盘价、52周高低
公司基本面 yfinance (Yahoo Quote API)
yfinance.Ticker("{ticker}").info		 市盈率、市净率、市值、行业、β系数
新闻动态 Yahoo Finance v1 Search API
query1.finance.yahoo.com/v1/finance/search?q={ticker}		 按相关性返回财经资讯，含标题、出版商、链接
多空对比 yfinance + Yahoo Quote API
shortRatio / shortPercentOfFloat / heldPercentInstitutions		 空头比例、机构持股比例；日级别"多空比"基于日内振幅估算
机构持仓 yfinance (institution-ownership API) 机构持有者明细、共同基金持有明细
资金流向 Yahoo v8 Chart (30m) → 自建估算模型 基于30分钟K线的OHLCV：上涨区间成交量×均价≈流入，下跌≈流出。
⚠️ 此为估算值，非交易所Level2精确数据
